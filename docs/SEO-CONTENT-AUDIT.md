## لینک‌های داخلی پیاده‌شده
- مقاله → خدمات، پروژه‌ی ویژه (هفت‌خان)، آثار، مشاوره، مقالات مرتبط (بر اساس برچسب مشترک).
- پروژه → مشاوره (CTA)، مراحل (`#stage-*` از صفحه‌ی اصلی).
- آثار → صفحه‌ی هر دسته → هفت‌خان و مشاوره.
- خدمت → سایر خدمت‌ها، فهرست پروژه‌ها، مشاوره.
- ریسه → فرم سفارش (`#order`) و مشاوره.
